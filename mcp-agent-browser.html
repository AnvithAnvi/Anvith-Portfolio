MCP Agent Browser

An agent that turns plain-language instructions into real browser actions.

Role
Solo project
Stack

Tested

The problemThe approachWhere it failsWhat I took from it

The problem

Browser automation scripts break when a page changes, and they need someone to write them. I wanted to say what I need in plain language and have an agent do the clicking.

The approach

A LangChain ReAct agent plans in a reason-then-act loop. It calls a structured tool-calling interface backed by Playwright, with actions to click, fill, navigate and extract.

Where it fails

I ran the agent across 20+ real workflows and kept notes on what went wrong. The failures clustered around three things: ambiguous instructions, prompt structure, and multi-step planning, where an early wrong step carries through the rest of the task.

What I took from it

Being able to see why an agent chose an action matters as much as the action itself. That question is what led to AgentWatch.
