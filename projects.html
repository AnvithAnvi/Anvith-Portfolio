RAFT ArXiv

Fine-tuned Phi-2 (2.7B) with QLoRA on a QA dataset built from 200 ArXiv papers, using an 80/20 oracle-to-distractor context ratio so the model learns to cite passages and refuse unsupported answers. A side-by-side evaluation UI compares it with Llama-3 on citation precision, faithfulness and refusal accuracy.
